# Notebooks

Dung notebook cho EDA, baseline nhanh, va error analysis. Code can tai su dung nhieu lan nen dua vao `src/ear_classifier/` de script va app cung goi lai duoc.

- `resnet50_training_analysis.ipynb`: notebook lich su cho run ResNet50 cu. Lineup benchmark hien tai da doi sang ResNet18, nen can tao artifact/notebook moi neu muon phan tich benchmark hien tai.
- `three_model_comparison.ipynb`: gom 3 model trong mot notebook de train, evaluate, so sanh metrics, learning curves, confusion matrix, checkpoint va du doan tren cung mot anh.
